# Portfolio AI — Design Spec
**Date:** 2026-05-06  
**Status:** Approved

---

## Context

A PWA for personal stock portfolio management with AI-driven analysis. The user registers, uploads a screenshot of their portfolio (or enters holdings manually), and receives a full AI analysis of each stock. A background service monitors news and sends Web Push notifications for material events affecting holdings. Supports US (NASDAQ/NYSE) and Israeli (TASE) stocks. UI in Hebrew by default with English toggle.

---

## Tech Stack

| Layer | Choice |
|---|---|
| Backend | Node.js + Express (single `server.js`, same pattern as food-logger) |
| Frontend | Single-file SPA (`public/index.html`, inline CSS + JS, Hebrew RTL) |
| Database | PostgreSQL on Railway |
| Hosting | Railway |
| AI | Claude Haiku (`claude-haiku-4-5-20251001`) |
| Stock data | `yahoo-finance2` (npm) — US + TASE tickers |
| News | NewsAPI (primary) + `cheerio` scraping of Motley Fool (fallback for earnings) |
| Notifications | Web Push API + Service Worker (VAPID keys) |
| Background | `setInterval` polling every 15 minutes |

## AI — Claude Prompts

### 1. Portfolio Screenshot Parser
```
User sends image.
System: Extract all stock holdings from this brokerage screenshot.
Return JSON: [{ ticker, exchange, quantity, avg_cost }]
If a field is unclear, omit it (don't guess).
```

### 2. Stock Analysis
```
System: You are a skeptical financial analyst. Given the following financial data for {TICKER}:
{yahoo_finance_data}

Provide:
1. Valuation assessment (cheap / fair / expensive vs sector)
2. Moat analysis (wide / narrow / none + why)
3. Management quality (1-2 sentences)
4. Future outlook (12-24 months)
5. "למה אני טועה?" — actively argue the bear case: what risks, threats, or valuation errors could make this analysis wrong?

Be concise and direct. No disclaimers.
```

### 3. News Significance Filter
```
System: Given this news article about {TICKER} and the user's alert_level ({1|2|3}):
Level 1 = only earnings, M&A, CEO/CFO departure
Level 2 = also analyst rating changes, lawsuits, guidance revision
Level 3 = all mentions

Decide: should this trigger a notification? Return JSON: { notify: true|false, category: string, summary: string (2 sentences), tone: string|null }
```

### 4. Earnings Call Summarizer
```
System: Summarize this earnings call article in exactly 5 bullet points for a skeptical investor.
Flag if management seemed evasive on: growth, margins, competition, or guidance.
Return JSON: { bullets: string[], evasion_warning: string|null }
```

### 5. Ecosystem Impact Analysis
```
System: News about {SOURCE_TICKER} may affect other stocks in the user's portfolio: {ALL_PORTFOLIO_TICKERS}.
Explain in 1-2 sentences how this news could impact each ticker (supply chain, revenue exposure, competition).
Only include tickers with a real, non-trivial relationship. If none, return [].
Return JSON: [{ ticker, impact }]
```

## Background Polling

```
setInterval(async () => {
  for each user with push_subscriptions:
    for each holding in user's portfolio:
      1. fetch latest news from NewsAPI for ticker
      2. filter out already-seen URLs (news_seen table)
      3. call Claude: News Significance Filter
      4. if notify=true AND alert_level matches:
         a. if category=earnings: call Earnings Call Summarizer
         b. call Ecosystem Impact Analysis for related tickers
         c. send Web Push to all user's subscriptions
         d. insert into news_seen
}, 15 * 60 * 1000)
```

## API Routes

```
Auth:
  POST /auth/register
  POST /auth/login
  POST /auth/change-password

Portfolio:
  GET    /api/portfolio          — get user's holdings
  POST   /api/portfolio/screenshot — Claude Vision parse → holdings preview
  POST   /api/portfolio/holdings   — save holdings (manual or confirmed screenshot)
  DELETE /api/portfolio/holdings/:id

Analysis:
  POST /api/analyze/:ticker     — fetch yahoo-finance2 + call Claude → save to holdings.analysis_json

Notifications:
  GET  /api/notifications       — paginated news feed
  POST /api/push/subscribe      — save push_subscriptions
  DELETE /api/push/subscribe    — remove subscription

Profile:
  GET  /api/profile
  PUT  /api/profile             — { language, alert_level }
```

## Rate Limiting

- `/api/analyze/*` — 20 requests/hour per user (Claude calls are expensive)
- `/api/portfolio/screenshot` — 10 requests/hour per user
- `/auth/*` — 10 requests/minute

## i18n

Simple inline object in `index.html`:
```js
const T = {
  he: { portfolio: 'תיק', notifications: 'התראות', settings: 'הגדרות', ... },
  en: { portfolio: 'Portfolio', notifications: 'Notifications', settings: 'Settings', ... }
}
```
Language switch updates `document.documentElement.lang/dir` and re-renders all text nodes.
